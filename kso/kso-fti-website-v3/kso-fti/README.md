# Website KSO FTI 
Website statis (HTML + CSS + JS biasa). Buka folder ini di VS Code, lalu klik kanan `index.html` > **Open with Live Server**.

## Struktur file
| File | Isi |
|------|-----|
| `index.html` | Beranda |
| `program.html` | Daftar 4 program kerja |
| `rukes.html`, `ruko.html`, `fti-cup.html`, `fti-sport.html` | Halaman tiap program kerja |
| `event.html` | Jadwal kegiatan (filter per program) |
| `galeri.html` | Galeri dokumentasi (filter per program) |
| `tentang.html` | Deskripsi biro, visi, misi, struktur biro |
| `css/style.css` | Semua tampilan (warna ada di `:root` paling atas) |
| `js/main.js` | Menu burger HP + filter |
| `images/` | Foto & logo (`logo-kso.jpg` = logo) |
